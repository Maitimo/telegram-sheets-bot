# 🤖 Telegram Bot для запису на послуги з інтеграцією Google Sheets

Асинхронний Telegram-бот на Python (`aiogram 3`), призначений для збору заявок від клієнтів та автоматичного збереження даних у Google Таблиці з миттєвим сповіщенням адміністратора.

## 🚀 Функціонал
* **FSM-покроковий діалог:** інтерактивне опитування клієнта (Ім'я -> Телефон -> Послуга).
* **Зручна навігація:** підтримка кнопки «⬅️ Назад» для зміни даних на будь-якому етапі.
* **Швидке надсилання контакту:** можливість поділитися номером телефону в 1 клік через `request_contact`.
* **Інтеграція з Google Sheets:** синхронізація заявки у реальному часі за допомогою API `gspread`.
* **CRM-сповіщення адміністратора:** автоматичне надсилання картки замовлення з клікабельним посиланням на профіль клієнта.
* **Захист даних:** збереження ключів доступу у змінних оточення (`.env`).

## 🛠 Технологічний стек
* **Python 3.10+**
* **aiogram 3.x** (Асинхронний фреймворк для Telegram Bot API)
* **gspread** (Google Sheets API)
* **python-dotenv** (Управління конфігураціями)
